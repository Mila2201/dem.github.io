Линейная регрессия: Предсказание баллов

16 марта 2026

📈 Линейная регрессия: Зависимость оценок от времени учёбы

Проект по машинному обучению: предсказание экзаменационных баллов на основе часов подготовки.

Шаг 1: Откройте Jupyter Notebook и введите код

# библиотека для работы с таблицами
import pandas as pd

# загружаем таблицу в память из файла task_regression.csv
dataset = pd.read_csv(r'Downloads/task_regression.csv', sep=';', decimal=',')
Задание: Вспомните, какой инструкцией можно вывести данные на печать? → Используйте print(dataset) или просто напишите dataset в ячейке.

Шаг 2: Построение графика зависимости

# отсортируем столбец "Часы" по возрастанию
dataset = dataset.sort_values(by='Часы')

# построение графика
import matplotlib.pyplot as plt
dataset.plot(x='Часы', y='Полученные. Баллы', style = 'o')
plt.title('Зависимость')
plt.xlabel('Часы')
plt.ylabel('Баллы')
plt.show()
Вывод: По графику видно, что существует положительная линейная зависимость между количеством изученных часов и процентом набранных баллов.

Шаг 3: Подготовка данных — разделение на атрибуты и метки

Атрибуты (X) — независимые переменные (часы). Метки (Y) — зависимые переменные (баллы), которые нужно предсказать.

X = dataset[['Часы']]
print(X)

Y = dataset['Полученные. Баллы']
print(Y)
Обратите внимание: X берётся в двойных скобках [['Часы']], чтобы остаться DataFrame, а Y — в одинарных ['Полученные. Баллы'], так как это Series.

Шаг 4: Разделение данных на обучающий и тестовый наборы

from sklearn.model_selection import train_test_split

X_train, X_test, Y_train, Y_test = train_test_split(
    X, Y,
    test_size=0.2,        # 20% данных — тестовая выборка
    random_state=42,      # фиксация случайности
    shuffle=True          # перемешать перед разделением
)

Шаг 5: Обучение алгоритма линейной регрессии

from sklearn.linear_model import LinearRegression

regressor = LinearRegression()
regressor.fit(X_train, Y_train)

print("Коэффициент (наклон):", regressor.coef_)
print("Свободный член:", regressor.intercept_)
Баллы = 2.85 + 9.48 × Часы
Интерпретация: - Студент, который не готовился вообще, в среднем получает ~2.85 балла. - Каждый дополнительный час подготовки добавляет ~9.48 балла.
